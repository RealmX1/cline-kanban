# Kanban Codex profiles 退役与存储保全

看板启动使用用户原生 Codex 配置，保留原生 `--profile` 与工作区会话历史隔离。任务模型、推理强度、权限与 Plan Mode 仍可独立选择。旧版配置管理接口、逐进程 writer、审批、同步和自动替换停止运行。

隔离目录链接用户的原生配置文件。目录内的原生相对文件引用以链接共享，保留项目层覆盖和带点的角色名。跨目录的相对引用须使用绝对路径。辅助 app-server 的 SQLite 启动参数固定到本次选定的存储。原生保存可更新链接指向的源文件。Kanban 不替用户保存、批量合并或放宽权限。当前任务上明确选择的权限优先。仍由旧设置继承的权限经原绑定核验后可用于同一原生会话。缺少可信权限来源时使用只读沙箱，沙箱外操作经过原生询问。新开局需要使用明确的任务权限。

在自然退出或正常续接时转换既有任务。切换实例前还须核验仍直接使用旧专用 home 的活进程；这类进程自然退出后才能转换旧 home 内的文件与 marketplace 副本。留存旧配置同步 SQLite、原 writer 清单、会话链接及工作流执行闭包，供历史核验与回退。旧隔离目录中的配置文件转换前归档到 `retired-configuration-snapshots`。原生会话 ID、归属及 SQLite 位置按清单与目录身份验证。可证明尚未恢复的旧草稿以稳定 ID 进入任务 Prompts。原始终端字节及不确定的提交状态继续保留。

| 存量 | 核验与恢复条件 |
| --- | --- |
| 活体或持久记录仍引用的旧 writer | 保留原目录和全部数据。等待所属原生进程退出，并核对历史、SQLite、草稿与恢复引用后重验。 |
| 旧 writer 缓存 | 只考虑实际归属已匹配且可重建的原生目录 JSON。受管会话的原生缓存使用稳定的 `codex-conversation-storage-home/cache`，已绑定用户目录的历史会话继续遵循其原生位置。后续本地部署备份排除 `remote_plugin_catalog` 和 `codex_apps_tools` 下保留命名形态的普通文件，源文件与其他同名路径保持原样。 |
| 部署备份、RVF 与同步工件 | 按原执行、接受回执、检查点和唯一成果边界核验。历史备份的指纹与引用保留原语义。缺证候选单独等待，有资格且获授权的候选可独立继续。 |

记录旧目录收口时，以实际安装版本、绑定会话、目录物理身份及唯一成果指纹确认恢复资格。只复用同一证据的有限重试，检测机读条件变化后再核验。无法证明的状态保持未知。停止或删除授权来自所属操作。CLI、运行时重启与升级不自动触发删除。

`9704e` 的三份旧备份缓存与真实 writer 同类缓存曾分别测得 87.164 GiB 和 29.109 GiB。该批合计 116.273 GiB 是历史独占物理块估计，不能作为本次释放量重复计入。其旧快照中 67 个接受项有 39 个引用前次执行。归属缺证及 `2f64b` 的既有会话保全暂停继续有效。

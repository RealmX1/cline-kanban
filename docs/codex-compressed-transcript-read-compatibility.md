## 读取边界

`src/agent-session-history/codex-transcript-read-source.ts` 提供普通与 Zstandard 文件的共享字节源。普通 JSONL 直接只读打开；压缩内容复用已有 `zstd-stream`，先流式核验到正常 EOF，再发布可读取来源。兼容 Node 22，不依赖系统 `zstd` 或较新 Node 的原生 Zstd API。

共享源解决格式、字节与文件版本，不替业务调用方猜会话身份。业务读取仍须校验原生 UUID、`session_id`、`thread_source` 及后台来源；元数据中的 subagent、internal、memory_consolidation 和 guardian_review 均不能成为主会话证据。续接预检继续执行原来的 3 秒边界，并补齐非用户 `thread_source` 与真实目录归属检查。

`nativePath` 始终指向原生存储。私有快照没有可供续跑使用的路径；缓存路径不能写入原生身份、数据库 rollout 指针或启动参数。

## 私有快照和预算

- 默认实例的解压快照总量固定为 256 MiB，使用 LRU 淘汰；代码中的 `EXPERIMENT_NODE:` 记录容量校准点。另以 64 个版本作为闲置快照句柄的淘汰目标，活跃读取租约不会被强行关闭。
- 同一物理源版本单飞解码，续接预检与正文读取共用全进程的两个解码席位；预检等待席位也可按原有截止时间退出，取消不会泄漏席位。版本绑定原生路径、device、inode、大小、mtime 和 ctime。
- 快照在私有目录以 `0600` 创建，完成后设为只读，正文开始写入前就解除目录引用。读取结束或进程退出释放句柄，重启不会留下整批解压副本。
- 超出容量、或现有活跃租约占满空间时，只保留完整性与长度等有限信息；范围读取流式丢弃无关内容，不把大文件常驻缓存。
- 正文、分页、父段截点和统计水位均使用解压后的 JSONL 字节。真实 I/O 成本另外记录压缩源和私有快照的实际读字节，不能把逻辑推进长度冒充磁盘 I/O。

元信息首行单独流式解析，丢弃巨大的 `base_instructions`，保留身份及 lineage 字段和原始行尾偏移；扫描受打开时长度及 3 秒时限约束。超大首行的统计水位按每次 256 KiB 的逻辑预算推进，抵达真实行尾时才计入这一条记录；正文预算不会因缓存中压缩文件很小而被缩小。

## 文件变化、游标和恢复

普通和压缩对应路径可以互换。文件消失或初始化期间发生 inode/版本变化时，有界重查一次；已知原生 UUID 的旧入口仍不存在时，只读同一存储中的可信 `threads.rollout_path`，核对真实路径及身份，不扫描别人的正文猜当前会话。缓存不构成新的身份或接受证据。

不透明分页游标内部版本为 2，绑定会话、分片、本地逻辑偏移和内容前缀摘要。等价压缩、解压和原子替换不使阅读位置失效；已读前缀被截断或改写仍返回 `snapshot_invalid`。普通旧游标在原来源仍可核验时继续兼容；已有完整前缀证据的旧稳定游标也能跨格式转换。缺少内容证据的旧物理游标在来源已替换时仍保持未知，沿用刷新判据。

问答缓存识别压缩文件与目录变化；提示词统计保留已确认提交身份并继续去重。压缩、缓存刷新和历史补证不刷新事件时间，不生成新用户回合，不把旧答案或失败记录改写成新发送成功。

损坏压缩、错误身份、越界路径或无法核验的祖先只阻止依赖该证据的动作。现有查询、文件变化和重启恢复路径会重验；源格式稳定且身份/完整性可验证后自动继续，不要求用户手工修复机器可查询的信息。

## 压缩归因与历史统计

Codex 0.166.0 的[压缩实现](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/rollout/src/compression.rs)定义后台 worker、启动/RPC 来源与至少 7 天未修改的候选条件，并进行编码、校验和发布后删除源文件。[启动接线](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/core/src/thread_manager.rs)与[元数据复制](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/rollout/src/compression/access_metadata.rs)说明它属于 Codex 共享内核机制，并明确保留 mtime；不是 macOS 透明文件系统压缩。

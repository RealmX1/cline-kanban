# 共享任务编辑器与项目归属分析

创建任务和编辑 Backlog 共用 `TaskEditorDialog`、设置分组、显示偏好和异步提交链路。已有卡的字段补丁与新卡身份分配仍由运行时各自的命令处理。主按钮分别显示“创建任务”和“保存更改”；连续创建和批量创建保留在创建模式中。

## 浮窗与草稿

`TaskEditorFloatingWindow` 使用 Radix 非模态模式，不渲染遮罩、不锁定 body 滚动，也不捕获背景焦点。标题栏支持指针拖动和收起，位置按视口约束，收起保留表单挂载。快捷键沿编辑器的 React 子树冒泡，背景输入和其他弹窗不会触发编辑器提交；输入法组字期间让开。

编辑会话按打开时的项目与任务固定。切换背景项目不会改变保存目标；另开编辑对象时立即保存被挂起的草稿，并提供“返回草稿”入口。新建草稿保存名称、正文、附件、全部启动设置和选定项目，恢复时不重新套用默认值。编辑草稿的会话模式也参与服务端去抖保存和迟到快照恢复。显式关闭创建与编辑都检查未保存更改。AI 分析期间允许继续编辑，旧输入的结果不会提交；进入保存阶段后禁用表单输入，避免在途保存关闭新输入。

跨项目导航保留浮窗的展开或收起状态；背景项目暂不可用不会触发编辑器关闭重置。打开时捕获的默认 Agent 和模型属于编辑会话，后台项目的默认设置变化不会重铺当前草稿；读取其他来源项目配置时核对会话身份，避免迟到结果覆盖新会话。

会话来源、用户选择的目标项目与已保存卡片的物理项目分别维护。分支只按选定目标校验；迁移确认后更新物理归属，关系草稿仍使用本次打开时的固定来源。来源看板先广播移除卡片时，编辑器保留提交快照，直到字段、迁移、关系和启动全部完成。关系或启动失败可向已保存项目重试，不重复建卡；恢复写入携带创建时间，防止覆盖同 ID 的新任务。输入失效保护只额外接受本轮明确采纳的项目和分支变更，正文等实际变化仍使旧提交失效。

## 设置显示偏好

字段显示有 `expanded`、`collapsed_in_group`、`hidden` 三态，首次全部展开。组末使用可换行按钮恢复组内收起项；隐藏项只从主滚动区底部“管理隐藏设置”恢复。显示状态不修改字段值，收起和隐藏保留控件挂载。

偏好位于全局 runtime config 的 `userInterfacePreferencesSharedAcrossBrowserOrigins.taskEditorSettingPresentationBySettingKey`，与项目、创建/编辑模式和浏览器 origin 无关。请求只发送发生变化的设置键，服务端在配置锁内合并；同一客户端按点击顺序保存。失败保留当前界面状态并明确提示未持久化。

剪贴板识别只临时揭示关系组，不改偏好。打开编辑器或从背景切回时读取剪贴板，内容变化才解析。完整短 ID 复用 `isCompleteShortTaskIdShapedText`，工作树路径解析 `.cline/worktrees/<taskId>/<repoFolder>` 后查询身份登记簿，并按当前或历史仓库目录名过滤。目录不必实际存在，目录名也不被当作唯一项目身份。多匹配时由用户选择；关系正在编辑时不覆盖其对端。浏览器拒绝读取后不反复请求权限，仍支持显式粘贴。

当前项目显示名与工作树最后一段都从仓库目录名派生，工作区 ID 另有去重机制；不同仓库可以同名，因此关系端点必须使用限定身份。

## Backlog 项目迁移

`taskCardAction.transferNeverStartedBacklogTaskToProject` 只接收尚未启动的 Backlog 卡，核对创建时间、目标分支、已有会话和工作树资源。保留任务 ID、创建时间、正文、图片、备注和关系身份。

迁移按全局迁移记录锁、排序后的双工作区锁执行。持久记录位于 `~/.cline/kanban/backlog-task-project-transfers/<operationId>.json`，阶段为 `prepared`、`target_saved`、`completed`。先保存目标，再移除来源；同一操作重试校验输入，重启后的相关卡片动作先恢复未完成记录。来源内容意外变化时保留证据，拒绝覆盖。

持久化捕获将迁移与普通删卡、建卡区别处理，只追加迁移完成事件。身份投影保持创建时的不可变关系节点，另记当前位置及历次位置别名；支持多次迁移和返回原项目，关系自然键不形成循环别名链。后续字段和会话事件在读侧归一到原身份，关系摘要同时保留当前位置、标题和列信息。旧整板快照不能将迁出的同一世任务重新建回原项目；缺少 revision 的目标整板保存也不能删除刚迁入的卡片，显式卡片删除及带当前 revision 的整板删除仍可执行。目标保存后发生中断时，恢复保留目标已经更新的正文、附件和备注，不用迁移记录中的旧副本覆盖。编辑请求携带创建时间门禁；迁移恢复后，旧客户端可查询限定身份并向当前位置重试保存。

关联任务悬停预览也按不可变身份读取一跳邻接，卡片与导航目标使用当前位置。邻居只迁移项目、名称和关系未变时，也会使旧分页游标失效，避免继续返回过时导航位置。

## 单轮 AI 分析

项目归属、查卡召回与解释、任务起名、关系建议和后台关系分诊统一使用无工具单轮 API。Settings 的“AI 任务分析”配置首选和备用 provider，沿用统一 Save/Cancel；模型、端点和凭据复用 provider 档案。默认首选 MiniMax、备用 DeepSeek，未配置 MiniMax 时直接使用 DeepSeek。旧 CLI 配置仅兼容读取历史，不再驱动新请求。详见 [API 主备路由](task-assistance-api-provider-routing.md)。

项目归属与查卡共享安全指令，使用独立轻量 Context：完整注册项目名与路径、每项目最多三条非 Trash 相关标题；没有相关标题时按最近时间选择。新任务正文完整保留，不加载通知归档、会话 recap 或既有任务完整正文。查卡继续保留共享 L1–L3、两阶段查询、候选完整要求、历史问题和图片归属。日志记录真实 provider、请求与实际模型、操作和阶段、用量及前缀哈希；上游未返回的缓存用量保持未知。

界面 Create/Save/Start 自动分析，也提供手动入口；CLI 和后台自动动作保持原语义。项目合适则继续，有建议时明确选择采纳或保留，失败时显示 toast 和保留原项目继续的入口。并发相同输入共用请求，批量创建逐项分析；关系保存失败不启动 Agent。

## 验证入口

- Web 单元测试覆盖编辑器、草稿、显示偏好、剪贴板解析和分析失败选择。
- `web-ui/playwright.task-editor-isolated.config.ts` 启动独占 Vite 端口，以受控接口验证桌面、手机、背景焦点、折叠隐藏和剪贴板关系预选。
- `backlog-task-project-transfer-through-runtime.integration.test.ts` 使用 HOME 与 Git fixture 隔离，验证账本身份、往返迁移、旧快照门禁及中断恢复。
- `task-project-assignment-single-turn-analysis.integration.test.ts` 使用隔离 HTTP API fixture，核验单轮次数、零 CLI 启动、完整新正文、独立轻量 Context 及旧设置兼容。

含原生账本的测试应使用与安装依赖相同的 Node；此工作区的共享原生依赖对应 Node 24，不在任务工作区重建共享 `node_modules`。构建前必须移开 `dist` 与 `web-ui/dist` 的共享软链，并指定隔离分发目录。

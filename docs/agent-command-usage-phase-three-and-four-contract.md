## 能力与范围

Agent 可直接复用 JSON 字段选择及当前任务完整快照配方，并从仓内原有分析入口核对结果、失败语义及完整成本。只扩展已有合成对照和指引，不增加运行时 API、通用脚本执行器、采集器、依赖或后台调度器。

真实材料沿用第二阶段最终观察的摘要绑定记录；只静态阅读，不执行原始命令。纯字段读取样本明确读取单个 JSON 的 `findings`；查询样本只证明原生查询存在，不能证明需要落盘或等同含 Git、owner、评审材料的组合调查。跨 Task/Session cohort 仍为 unknown，未达到新增通用能力门槛。私有定位与命令留在任务持久目录。

## 冻结的结果契约

| 目标 | 成功 | 失败与副作用 | 适用边界 |
| --- | --- | --- | --- |
| 读取必需 JSON 字段 | 单个对象的 `findings` 作为一个 JSON 值输出；允许排版差异，保留 null、false、0、空字符串、空对象和空数组 | 缺字段、空输入、多个文档、坏 JSON、错误根类型或文件缺失时非零且无 stdout；输入不变，不执行字符串内容 | UTF-8、工具可无损表示的 JSON 值；超出 jq 精度范围的数值使用 Python。不得用 `-e` 把合法 false/null 当失败或用默认值抹去差异 |
| 保存当前任务完整快照 | 使用会话绑定原生查询；核对任务及注册项目，保留全部原始 JSON 字节；新文件及旧文件替换后均为600；同目录原子替换 | 查询、解析、身份或写入失败时非零，旧文件不变；拒绝目标目录、普通及悬空 symlink；清理暂存文件 | POSIX、jq、既有运行时绑定入口；在当前用户控制、无并发写入的私有目录运行；会话归属由 `get-current-task` 原生校验，不从返回的主会话摘要猜测协作者身份 |

原子替换保证可见内容完整，不承诺断电后的磁盘持久性、恶意并发路径替换或多个写入者的协调。收到可处理信号时清理；SIGKILL/断电后可能留下600暂存文件，重启只能核对绑定目标后删除旧暂存，不能把暂存直接当完成快照。

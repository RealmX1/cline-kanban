状态：PLAN-READY。来源：本任务上一回合的 proposed_plan，以及用户本回合明确要求的「Implement the plan.」。

## 实现合同

- 能力：新建 Kimi 任务无需手动补发，完整初始提示词在原生输入框真正就绪后仅投递一次。
- 范围：启动信任门禁、Kanban 工作树的进程级信任、原生信任确认输入、运行时热接管、自动回归及部署后验证定义。
- 非目标：更改权限档位、模型选择、已有原生接受协议、通用消息系统；不向已经手动启动的 7c4fd 重发正文，不提交、推送或部署。
- 验收：信任未完成或启动超过 5 秒时不得粘贴正文；信任完成后自动继续；正文完整且唯一，真实原生用户消息确认接受；人工编辑依旧让位。
- 影响面：Kimi adapter/readiness、session manager、相关 guarded tests、隔离原生探针与接入文档。
- 风险：原生信任对话框有底层输入框，不能仅凭输入框字形或超时认定就绪；人工信任确认不能走普通草稿接管；异步读屏与热接管须重新核对进程身份。
- 验证：相关 guarded tests、根/Web 类型检查、Biome、隔离构建，以及真实 Kimi + 隔离 HOME + loopback 模拟模型的首发与原生接受检查。

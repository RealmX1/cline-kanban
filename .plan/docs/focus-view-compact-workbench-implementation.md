# Focus View 紧凑标题与任务工作台实施合同

状态：用户已在本轮明确批准实施。来源为用户提供的《统一 Focus View 标题与紧凑任务工作台》完整方案。

能力：统一 Focus View 分组标题，合并工作台导航与内容标题，通过浮层保留 TUI 信息和任务操作。

范围：Stage 与 sticky 孪生标题、Pinned/Running/Cache Warm/Recent/Shelved；工作台模块头部组合；问答和资源浮层；底部任务菜单和手机控制区。

不在范围：主题重设计、服务端配置、持久化迁移、部署、Git 提交与同步，以及下文待评估方向。

验收：桌面标题 32px、分组间距 4px；箭头折叠与标题定位分开；每区一条工具栏；换格和断点不卸载模块；待答、失败、停止及取消自动动作仍可达；浮层内部滚动、Escape 与焦点返回；手机触控入口至少 44px。

涉及面：`detail-panels/` 分组/工作台/终端组件、`card-detail-view.tsx`、模块内容标题、相关组件与 Playwright 测试、滚动几何与文档。

风险：sticky 几何、原生终端连接连续性、iframe 身份、手机浮动入口与安全区遮挡。

实施切片：

1. 分组标题：先验证折叠与跳转独立、共享高度，再验证已有滚动与焦点卡回归。
2. 工作台：先验证导航进入模块原有标题、换格和布局后输入及 iframe 节点相同，再改模块接线。
3. TUI：先验证按需查询与身份切换、菜单操作资格，再改浮层和移动控制区。

验证：相关 `npm run web:test -- …`、根和 Web 类型检查、Biome、隔离 Playwright 与构建。构建先解除本工作树 `dist`、`web-ui/dist` 的共享软链，并显式设置 `KANBAN_BUILD_DISTRIBUTION_OUTPUT_DIRECTORY`。

## 待评估方向（本轮不实施）

- 跨主题次要文字对比度：现有 `text-text-tertiary` 广泛用于计数与元信息；位置 `styles/globals.css`、分组与资源组件；后续对每个现有主题实测文本对比度并验收。
- 首页列头一致性：跨项目分区组件同时服务首页横列与 Focus View；本轮仅替换 Focus View 紧凑标题；后续核对首页窄列和横向滚动。
- 空态占高：资源、工作台、探索地图有各自空态；后续以实际内容和断点测量占高，再统一必要的最小高度。
- 全局 Escape 优先级：现有菜单、浮层、终端搜索与前台展开分别处理 Escape；本轮沿用 Radix 的最上层关闭，后续覆盖多层叠加的全局顺序。

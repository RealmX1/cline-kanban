1. 即时投递也写入既有持久投递存储；不进入等待空闲调度，不消耗其容量，不被合并或重排。
2. 排队、即时、启动投递共用投影和 Queue，消息类型、来源、策略与结果独立表达；稳定 ID 防重复记录。

4. 未确认与已送达分开显示；以精确身份绑定的回执补证，不盲目重发；重启后恢复可观察状态。

# Codex 异常退出后的原生会话恢复实现合同

状态：`PLAN-READY`。依据：本任务此前给出的修复方案，以及用户本轮原话“如果能回写的话也回写,然后继续计划中的工作”。

能力：Codex 异常退出后按当前可信原生身份恢复，保留原生规划、批准和实施状态，不重新投递任务初始需求。

范围：`runAutoRestartNow`、主会话复用现有持久身份补证、同证据三次及十五秒间隔、退出现场诊断、相关自动测试；在已有授权内补齐 `1cf36` 的真实身份回写。

范围外：不伪造批准或 hook，不执行 `1cf36` 的功能实现，不推断那次原生退出 `101` 的未知原因，不提交、同步或部署。

验收：异常退出后首发次数不增加；清空上下文后恢复最新原生 ID；身份或转录迟到时自动补证，跨重启保存预算和恢复请求；Stop、取消、换代与责任变化均阻止旧恢复；换代前保全有界退出快照。

影响面：`src/terminal/session-manager.ts`、现有原生身份恢复模块、诊断 journal、加性契约注释、运行时测试与原生集成测试。

风险：陈旧身份或异步恢复可能选错会话；通过本代独享端点、身份和目录匹配、停止前转录预检及异步边界复核约束。

验证：相关 guarded 测试、根项目和 Web UI 类型检查、改动文件 Biome 检查；隔离 HOME、CODEX_HOME、CODEX_SQLITE_HOME 的原生回归与隔离构建。收尾登记真实部署实例的残余验证。

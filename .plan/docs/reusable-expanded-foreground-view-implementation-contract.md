# 统一前台展开视图实施合同

状态：PLAN-READY。来源：本任务获批方案，以及用户随后明确要求 “Implement the plan.”。

- 能力：可视化、探索地图、Relations 共用前台展开宿主与 URL 导航；从关联预览以被预览任务为中心进入 Relations。
- 范围：稳定内容实例、完整任务身份、返回与浏览器历史、键盘触屏等价入口、错误恢复、独立链接与旧可视化链接兼容。
- 边界：沿用领域控制器与关系账本；地图展开不触发付费维护；刷新只恢复内容定位与已有草稿，不持久化阅读位置。
- 验收：展开收回保留 iframe 和图谱阅读状态；跨 workspace 与同 ID 不串卡；链接刷新可恢复；临时读失败有界恢复；显式保存与维护门禁继续有效。
- 影响面：Web UI 组合根、工作台、三类面板、关系读取 selector、可视化内容消息桥。
- 验证：根 guarded 相关测试、web-ui 测试、两套 typecheck、Biome、隔离构建与 Playwright。

## 实施切片

1. 导航与身份：URL 往返、历史状态、完整一世 selector，先验证失败测试。
2. 稳定前台宿主：复用 Radix FocusScope，保持 DOM 与控制器，处理返回、焦点及响应式宿主生命周期。
3. 领域接入：可视化版本与消息桥、地图免费读取、Relations 图与显式建模、跨任务入口。
4. 自动化与交接：隔离浏览器验证、故障恢复、构建检查与部署后验证注册。

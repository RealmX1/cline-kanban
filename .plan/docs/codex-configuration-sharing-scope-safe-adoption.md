# Codex 配置范围与安全生效实施合同

依据用户批准的 `approved-plan.md` 实施，计划状态为已批准、可实施。

- 能力：每次配置修改可选择仅本会话或所属 profile；共享可受保护撤回；配置按热更新资格与 cache 风险安全生效。
- 范围：runtime 契约、持久记录、字段归属、补偿传播、草稿桥接、通知／设置／历史共用下拉及自动化验证。
- 范围外：修改全局 Codex 配置、调整后续修改的默认范围、扩大 hook 信任权限、部署运行实例、Git 提交或远端同步。
- 验收：双向切换、续接保值、下一次修改恢复默认；并发与 A→B→A 保护；重复与失联回执恢复；完整启动变化的 cache 风险判定；Stop／待答／后台执行保护；文字草稿无损恢复；窄屏与键盘操作。
- 风险：撤回误覆盖新决定、跨代归属误认、补偿被反向共享、草稿丢失或意外提交。所有路径保留版本、身份与持久提交门禁。

按可独立验证的行为分段实施：

1. 安全采用：先增加混合风险回归，确认只有全部变化均已知不影响 cache 时才自动重启。
2. 范围与撤回：先增加局部／共享、完整权限组、版本及幂等回归，再实现原值快照与受保护补偿。
3. 草稿保全：复用原生编辑器桥接，将正文持久保留于续接记录；失败保留旧进程，恢复不写 Prompts。
4. 统一界面：共用 Radix 范围下拉，普通自动共享进入提醒；处理与展示独立，历史仍可操作。
5. 验证交付：相关 guarded tests、Web 测试、根／Web 类型检查、隔离构建、Playwright 和隔离真实 Codex 回放，注册部署后验证。

产物和验证证据保存在本任务目录内，保持跨重启可读；临时隔离实例不使用真实 HOME 或关系账本。

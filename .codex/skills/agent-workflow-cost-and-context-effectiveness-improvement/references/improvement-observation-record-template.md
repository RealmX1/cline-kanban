# 改进观察的轻量记录

按需写入项目已有文档或持久产物；可简写，不要求新数据库或固定文件布局。

| 记录项 | 本次内容 |
| --- | --- |
| 目标与证据 | 要完成什么；来源、版本及必要证据入口。 |
| 选择与理由 | 选择哪些手段、工具及适用范围；简述理由。 |
| 前后观察 | 模型轮次与工具调用分别记；Agent输出、输入、实际费用及能力表现有证据则记，缺失为unknown；注明字符等代理量。 |
| 返回约定 | 直接提供的信息、相关错误诊断和按需详情入口。 |
| 当前结论 | 可为整体、单项或阶段性成功，也可保持未知；同时记录代价。 |
| 后续复查 | 值得复查的变化，以及保留、调整或回撤的依据。 |

新证据改变结论时保留先前观察及其版本，用关联修订说明变化，不将历史失败或不确定改写成成功。
